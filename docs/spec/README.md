# Scalar Network — Specification Documents

Dokumen spesifikasi protokol Scalar Network terdiri dari tiga dokumen:

| Dokumen | Isi | Format |
|---------|-----|--------|
| **SCALAR-PROTOCOL** | Aturan protokol, semua parameter OSSIFIED/CONSTRAINED, governance | [Markdown](SCALAR-PROTOCOL.md) |
| **SCALAR-TECHNICAL** | Circuit specification, algoritma, benchmark, implementasi | [Markdown](SCALAR-TECHNICAL.md) |
| **SCALAR-SECURITY** | Soundness analysis, formal verification, threat model, audit | [Markdown](SCALAR-SECURITY.md) |

## Prinsip Dokumen

- **Tidak ada versi** — setiap dokumen selalu merepresentasikan state terkini
- **Cross-reference** — tidak ada duplikasi antar dokumen
- **Tunggal per domain** — satu dokumen untuk satu domain
